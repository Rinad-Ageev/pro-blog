# RRA 创始人日记

[Русский](README.ru.md) · [English](README.md)

我是 RRA。在这里，我讲述自己推动 ERP（企业资源计划）、专用工作平台、交易平台和 AI 智能体开发的经历。我负责推动开发，也会把自己的贡献与其他参与者的工作区分开来。

仓库的人工管理已经不够用了，我想先用一个临时方案补上眼前的缺口。在 GPT 的帮助下，这个方案逐渐发展成 ERP。[第一篇文章](posts/001-why-my-own-erp.zh-CN.md)根据我的回忆讲述这段经历。确切的起始日期尚未还原，实施仍在进行。下面另列有记录支持的开发里程碑。

我想展示从问题和决定，到具体工作、核实后的结果、困难及下一步的过程。目前没有可供日记使用的、经证实的节省数据或用户评价。公开材料不包含非公开代码或内部业务数据。
